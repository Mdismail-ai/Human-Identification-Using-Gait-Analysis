Human Identification Using Gait Analysis
Overview

This project identifies and classifies humans based on their walking pattern (gait) using computer vision and machine learning techniques.

Technologies Used

Python 3.8

OpenCV

NumPy

Pandas

Matplotlib

Scikit-learn

Seaborn

Installation

Install the required packages:

pip install numpy==1.20.3
pip install pandas==1.3.5
pip install matplotlib==3.1.1
pip install scikit-learn==1.0.2
pip install opencv-contrib-python==4.3.0.36
pip install seaborn==0.11.2

Run the Project
python GaitClassification.py run server
